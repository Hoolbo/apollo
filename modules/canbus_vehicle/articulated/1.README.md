# Articulated Tracked Vehicle — Canbus 适配总结

## 1. 项目概述

本模块为铰接履带车（前车 FCBee2 + 后车 Hunter SE）在 Apollo 框架下的 Canbus 适配层。通过单路 CAN 总线（`can0`）同时控制两台车体，配合自研的 MPC Controller 和 CILQR Planner 实现铰接车的自主导航。

### 架构位置

```
CILQR Planner → MPC Controller → ControlCommand → Canbus Component → ArticulatedVehicleFactory
                                                                          ↓
                                                            ┌─────────────┴─────────────┐
                                                            │                           │
                                                     前车 FCBee2                   后车 Hunter SE
                                                     (Intel 小端)                 (Motorola 大端)
                                                    0x233, 0x223               0x111, 0x421
                                                    0x23C, 0x22C, 0x20C        0x221, 0x211
```

| 报文名 | CAN ID | 方向 | 车体 | 字节序 | 状态 |
|---|---|---|---|---|---|
| ACU_DriveMotor | 0x233 | 发送 | 前车 | Intel LE | ✅ |
| ACU_EPS | 0x223 | 发送 | 前车 | Intel LE | ✅ |
| DriveMotor_ACU | 0x23C | 接收 | 前车 | Intel LE | ✅ |
| EPS_ACU | 0x22C | 接收 | 前车 | Intel LE | ✅ |
| VCU_ACU_General | 0x20C | 接收 | 前车 | Intel LE | ✅ |

### 2.3 控制逻辑

- **前车速度**：从 `ControlCommand.speed`（m/s）转换为 km/h 后下发
- **前车转向**：从 `ControlCommand.steering_target`（前轮角度，度）× steer_ratio(6.0) 转为 EPS 电机角度后下发
- **后车指令**：从 `ControlCommand.header.status.msg` 解析字符串 `v_rear=X,delta_rear=X`，直接透传 m/s 和 rad
- **使能顺序**：后车 `CanControl` → 等待 100ms → 前车 Enable
- **安全保护**：解析失败时后车归零；Emergency/Disable 时前后车全部归零

### 3.2 CheckResponse 逻辑

当前 `CheckResponse()` 直接返回 `true`（与 mycar 一致），适用于调试阶段。正式部署时可根据需要增加对前车 EPS/DriveMotor enable 反馈和后车 `Control_Mode` 反馈的校验。

### 3.3 长期优化

- 将 `header.status.msg` 字符串协议升级为专属 `ArticulatedControlCommand.proto`
- 增加后车 CAN 通信超时检测（Message_Count 递增监测）

## 4. 依赖关系

本模块运行需要以下组件：

| 组件 | 说明 |
|---|---|
| `modules/canbus` | Canbus 框架（`CanbusComponent`），不需要修改 |
| `modules/control/mpc_controller` | 自研 MPC 控制器，输出四通道指令 |
| `modules/planning/cilqr_planner` | 自研 CILQR 规划器 |
| CAN 硬件 | 单路 CAN 接口（`can0`），波特率需与前后车一致 |
